**Computer Vision & Document AI · January–June 2026**

> Extracting meaningful signals from medical documents with varied layouts.

## 🚀 Projects worth exploring

### ⚽ [World Cup Forecasting Platform](https://github.com/AryaDesai241104/wc2026-forecasts)
**Statistical forecasting meets a working web application.**

Built a football forecasting platform with data ingestion, scheduled updates, and a Next.js interface. Evaluated forecasts on **128 held-out matches**, achieving a macro-averaged **Brier score of 0.197**; goalscorer precision@10 reached **0.70**.

`Python` `TypeScript` `Next.js` `DuckDB` `PostgreSQL` `GitHub Actions`

### 🚚 [Adaptive Logistics Dashboard](https://github.com/AryaDesai241104/adaptive-logistics-dashboard)
**Route planning with competing objectives and changing conditions.**

Built an interactive dashboard to compare route cost, emissions, and delivery lateness. Used **NSGA-II multi-objective optimization**, fuzzy route-risk scoring, and particle swarm optimization, with dynamic replanning for new orders and vehicle breakdowns.

`Python` `Streamlit` `Optimization` `Fuzzy Logic` `NSGA-II`

### ✋ [Project ARC · Gesture-Controlled Mouse](https://github.com/AryaDesai241104/Project_ARC)
**A webcam, hand landmarks, and a different way to interact with a computer.**

Mapped hand gestures to cursor movements and clicks using **OpenCV and MediaPipe**. Trained a **Random Forest gesture classifier** with stratified train/test splitting and classification reports on collected hand-landmark features.

`Python` `OpenCV` `MediaPipe` `Scikit-learn` `Computer Vision`

### 🌱 [AuraGrow · Farming Simulator](https://github.com/AryaDesai241104/AuraGrow)
**Learning decisions through rewards and consequences.**

Implemented **Q-learning and SARSA agents** in a **6,050-state farming simulation**, with a Streamlit interface to compare rewards and harvesting outcomes.

`Python` `NumPy` `Reinforcement Learning` `Streamlit`

### 📊 [Student Score Predictor](https://github.com/AryaDesai241104/Score_Predictor)
**From raw records to predictive features.**

Extracted student records from **SQLite**, explored distributions and correlations, and engineered study-efficiency and healthy-routine features. Built preprocessing workflows for missing values, categorical encoding, scaling, and predictive modeling.

`Python` `SQL` `Pandas` `Scikit-learn` `Exploratory Data Analysis`

## 🧩 A recent build: Local Resume Builder

I built a local Python workflow to make application tailoring more systematic:

```text
Job description + sourced experience
                 ↓
Skill confirmation → project & coursework selection
                 ↓
One-page LaTeX resume + matching cover letter
                 ↓
PDF validation + evidence report + score logbook
```

It combines **concept matching, bounded candidate search, optional local Ollama selection, and PDF validation**. Confirmed experience stays separate from coursework, and an internal coverage score stays separate from external ATS results.

The project includes modular Python code, reusable LaTeX templates, source provenance, and **20 automated tests**.
